# Rewind Display Branding

Rewind Display is a Retail Rewind branded fork of OpenSurv for dedicated camera-wall appliances.

The fork keeps OpenSurv's internal Linux user, session, and config paths for compatibility:

- Runtime user: `opensurv`
- Config symlink: `/etc/opensurv`
- App home: `/home/opensurv`
- LightDM session: `opensurv`

Retail Rewind-specific branding lives in:

- `surveillance/images/retail-rewind-logo.png`
- `surveillance/images/retail-rewind-icon.png`
- `surveillance/images/loading.png`
- `surveillance/images/connecting.png`
- `surveillance/images/placeholder.png`
